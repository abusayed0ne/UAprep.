# Stage H — Hardening implementation

Implemented code gates include strict validation, tenant and ownership predicates, deny-by-default permissions, separation-of-duty tests, answer-key DTO boundaries, secure response headers, correlation IDs, idempotency constraints, immutable published versions, audit events, consolidated migration validation, and CI type/test/build/audit checks.

Distributed rate limiting, WAF/TLS, centralized logs, monitoring, backup/restore, real authentication/MFA, payment adapter verification, database-backed concurrency tests, and production threat-model exercises require deployed infrastructure and remain in the final manual runbook.
